# Separate preview learning from General Release evidence

Bruno.Ai uses Owner Preview, Trusted Preview, External Beta, and Initial General Release as ordered
audience boundaries separate from Limited Operation and Core Operation. Preview Qualification and
Learning Rounds may advance product understanding but cannot satisfy Connected Acceptance or Founder
Acceptance Evidence; Initial General Release instead requires independently released OpenAI and
Anthropic, the full core capability set, and a fresh exact-candidate acceptance cohort. This slower
boundary was chosen over accumulating owner, friend, or coached-beta observations because those
participants cannot provide independent proof of a safe, self-serve commercial product.
